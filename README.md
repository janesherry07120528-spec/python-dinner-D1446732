## 3. 問題回答

**問題一：為什麼 `"4"` 要先轉成數字，才能用於本題的分攤計算？**
> 在 Python 中，加上引號的 `"4"` 是字串（`str`）型別，代表文字而非數值。字串無法直接與數值進行數學除法運算（執行 `1220.0 / "4"` 會發生 `TypeError` 錯誤），因此必須先用 `int()` 轉換成整數型別，才能正確算出每人分攤金額。

**問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？**
> 若先扣折價券再算服務費，計算過程如下：
> - 折價後餐費：$1200 - 100 = 1100$ 元
> - 服務費：$1100 \times 0.10 = 110$ 元
> - 應付總額：$1100 + 110 = 1210$ 元
> 
> 這比題目規定的 **1,220 元** 少了 **10 元**。原因是計算服務費的「基數」不同：題目規定以「原始餐費 1,200 元」計算 10% 服務費（120 元），而先扣券會讓計算服務費的基數減少 100 元，連帶使服務費減少 $100 \times 10\% = 10$ 元。
